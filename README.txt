PLEX app – what these files are
index.html, manifest.webmanifest, sw.js, icon-*.png = the PLEX phone/desktop app (no rig data inside).
The data comes from your PLEX Cloud Google script and needs the access code (VIEW key).
Put all files on any https web host (GitHub Pages: free). Share:  https://<your-site>/#k=<VIEW key>
